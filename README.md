# WayMark – Personal Work Management System

## Project Proposal

### Project Description

WayMark is a frontend-only personal work management web application designed to help users organize and manage their daily tasks in one place. The application provides a dashboard where users can view their tasks, track their progress, manage task priorities, and organize their work using different utilities.

The application is built using HTML, CSS, and JavaScript without using any external JavaScript libraries or frameworks. Browser-based storage is used to store and manage user data.

---

## Goals

The main goals of WayMark are:

- To provide a simple and organized workspace for managing daily tasks.
- To allow users to create, view, update, and delete tasks.
- To categorize tasks according to their priority.
- To allow users to manage their work through different sections such as Tasks, Calendar, and Notes.
- To create a responsive application that works on mobile, tablet, and desktop screens.
- To demonstrate the HTML, CSS, and JavaScript concepts.

---

## Specifications

### Technology Stack

- **HTML** – Used to create the structure of the application.
- **CSS** – Used for styling and responsive layouts.
- **JavaScript** – Used to implement application logic, CRUD operations, and interactive features.
- **Web Storage** – Used to store application data in the browser.
- **Service Workers** – Used for browser-based notifications and background functionality.

### Main Features

- Dashboard for viewing an overview of work.
- Create new tasks.
- View existing tasks.
- Update task information.
- Delete tasks.
- Assign task priorities.
- Track task completion.
- Calendar for organizing tasks and deadlines.
- Notes section for storing important information.
- Responsive design for mobile, tablet, and desktop.
- Browser-based data storage without a backend database.

---

## CRUD Operations

WayMark implements CRUD operations for task management:

| Operation | Description |
|-----------|-------------|
| Create | Add a new task |
| Read | View saved tasks |
| Update | Modify task details or status |
| Delete | Remove a task |

Task information is stored using browser storage so that the data can be maintained without a backend database.

---

## Responsive Design

WayMark is designed to work across different screen sizes:

- Desktop
- Laptop
- Tablet
- Mobile

CSS media queries are used to adjust the layout, spacing, and components according to the screen size.

---

## Design

The application follows a simple and clean workspace-style design. The interface uses a sidebar for navigation and a main content area for displaying tasks and utilities.

The primary color theme uses shades of purple along with white and light gray backgrounds to maintain a simple and consistent appearance.
